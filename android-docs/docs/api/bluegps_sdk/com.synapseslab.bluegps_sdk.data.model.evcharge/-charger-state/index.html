ChargerState

data class ChargerState(val bookingId: String, val resourceName: String, val bookingStart: String, val bookingEnd: String, val status: ChargerStatus, val statusLabel: InternationalizedString, val message: InternationalizedString, val icon: String, val style: ChargerStyle, val button: ChargerButton? = null, val soc: Double? = null, val energyDeliveredWh: Double? = null, val sessionStartTime: String? = null, val errorCode: String? = null, val timestamp: String) : Parcelable

Snapshot of the state of a charging station, identical wherever it appears: the chargerState of the active bookings and the data of the CHARGER_STATUS events.

The optional fields are omitted from the json when not applicable, they are never serialized as null.

Parameters

bookingId

id of the booking.

resourceName

name of the EPARK resource, ready for the title of the card.

bookingStart

start of the booking window, ISO UTC: convert to local time.

bookingEnd

end of the booking window, ISO UTC: convert to local time.

status

the status of the station.

statusLabel

the status label, both text and i18n are always valued.

message

the message for the user, both text and i18n are always valued.

icon

name of the icon of the design system, to render as it is.

style

color of the badge and of the text.

button

present only when an action is possible, otherwise no button.

soc

state of charge in %, only with an open session and only when the vehicle reports it: on AC wallboxes it is usually missing, a charging card without percentage is the normal case.

energyDeliveredWh

energy delivered in Wh, only with an open session.

sessionStartTime

start of the session, ISO: the elapsed time is computed by the client.

errorCode

error code of the provider, absent when there is no error.

timestamp

instant the status was computed, ISO.
