BeaconScanDiagnostics

object BeaconScanDiagnostics

Catalog of the beacon scan events, sent on BlueGPSDiagnostics under DOMAIN.

Android can silently degrade a BLE scan (screen off, process importance, Bluetooth toggled): from the app it looks like "no beacon in range". These events tell what changed around a gap. Transitions only, never one event per ranging cycle.
