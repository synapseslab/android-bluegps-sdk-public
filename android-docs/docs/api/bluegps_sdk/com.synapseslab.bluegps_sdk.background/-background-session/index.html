BackgroundSession

interface BackgroundSession

The period in which the SDK keeps the app working in the background, behind one ongoing notification whose content belongs entirely to the app.

One session per process, reached as BlueGPSLib.instance.backgroundSession. The same concepts, names and behaviour exist in the iOS SDK (contract "Background Session", draft 0.3), so a React Native or Flutter plugin can map the two one to one.

While a session runs, advertising, beacon scanning and the ia-location and ips positioning work under its notification: the user sees one notification, not one per service.

abstract fun <C> start(channel: IndicatorChannel, initial: C, updates: Flow<C> = emptyFlow(), render: <Error class: unknown class>.(C) -> Unit): Boolean

Starts the session and shows its notification at once, drawn by render with initial. Call it with the app in the foreground: from the background the indicator is IndicatorState.Unavailable with UnavailableReason.REQUEST_FAILED and the session runs without it.

abstract suspend fun stop()

Stops the session: cancels the collection of updates, stops advertising and the work running under the session, removes the notification and reports SessionEvent.Stopped once. Does nothing when idle.
