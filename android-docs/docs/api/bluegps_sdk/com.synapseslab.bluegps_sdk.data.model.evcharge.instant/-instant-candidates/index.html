InstantCandidates

data class InstantCandidates(val status: InstantPoolStatus, val candidates: List<InstantCandidate>? = null, val queueLength: Int? = null, val openingHours: List<OpeningHours>? = null) : Parcelable

The free spots right now, from GET instant/candidates. Read only: nothing is held until the request.

Parameters

status

state of the pool.

candidates

InstantPoolStatus.OPEN only, in a stable order.

queueLength

InstantPoolStatus.FULL only: 0 means no free spot, more than 0 means someone is already waiting and, first come first served, the only action is to queue.

openingHours

InstantPoolStatus.CLOSED only.
