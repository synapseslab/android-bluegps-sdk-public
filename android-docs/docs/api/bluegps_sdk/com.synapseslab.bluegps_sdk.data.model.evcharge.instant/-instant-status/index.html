InstantStatus

data class InstantStatus(val status: InstantState, val bookingId: String? = null, val resourceName: String? = null, val phase: InstantPhase? = null, val holdUntil: String? = null, val graceUntil: String? = null, val queuePosition: Int? = null, val snoozedUntil: String? = null, val openingHours: List<OpeningHours>? = null, val wsUrl: String? = null) : Parcelable

The instant charging state of the user, from GET instant/status and from the pushes of its channel, that carry the same object.

Only status is always present: the other fields are absent from the JSON when they do not apply, never null. The instants are UTC ISO strings.

Parameters

status

where the user is in the flow.

bookingId

InstantState.ASSIGNED only: the same id of the active booking.

resourceName

InstantState.ASSIGNED only: the name of the spot.

phase

InstantState.ASSIGNED only.

holdUntil

InstantPhase.HOLD and InstantPhase.PLUGGED only: the charge has to start before it, otherwise the booking is cancelled. Always a whole minute. Base of the countdown.

graceUntil

InstantPhase.GRACE only: the car has to be moved before it.

queuePosition

InstantState.QUEUED only, 1 based.

snoozedUntil

InstantState.QUEUED after a decline only: no spot is offered before it.

openingHours

InstantState.CLOSED only; empty means no instant spot configured.

wsUrl

relative path of the channel, uuid included. A fresh one is minted by every status call; absent from the pushes of the channel.
